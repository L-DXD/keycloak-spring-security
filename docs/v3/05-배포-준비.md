# 05. 3.0.0 배포 준비

## 2. SECURITY 지원 범위 [제안, 이봉승이 정함]

2.x는 Spring Boot 3.5 위에 있다. 3.5의 무료 지원은 2026-06-30에 끝난 것으로 알려져 있다(정하기 전에 spring.io의 Spring Boot 지원 일정에서 확인).

| 안 | 2.x | 장단점 |
|---|---|---|
| A (제안) | 3.0.0 뒤 3개월 동안 보안 수정만(`2.x` 브랜치, 2.0.4…). 그 뒤 지원 끝 | 옮길 시간을 준다. 수정은 `2.x`에만 |
| B | 3.0.0이 나오면 바로 지원 끝 | 일이 가장 적다. 옮기지 못한 앱은 수정을 못 받는다 |
| C | 쓰는 앱이 모두 옮길 때까지 보안 수정 | 기한이 없다 |

A로 정하면 SECURITY 표 맨 위에 아래 두 줄을 넣는다(날짜는 배포일 기준).

```markdown
| **3.0.x** | **권장** | Spring Boot 4.1 · Spring Security 7.1. 2.x에서 옮기는 법은 [docs/MIGRATION-v3.ko.md](docs/MIGRATION-v3.ko.md) |
| 2.0.3 | 보안 수정만 (YYYY-MM-DD까지) | Spring Boot 3.5. 수정은 `2.x` 브랜치에서 2.0.x로 낸다. 기한 뒤에는 지원하지 않는다 |
```

```markdown
| **3.0.x** | **Recommended** | Spring Boot 4.1 · Spring Security 7.1. To migrate from 2.x see [docs/MIGRATION-v3.md](docs/MIGRATION-v3.md) |
| 2.0.3 | Security fixes only (until YYYY-MM-DD) | Spring Boot 3.5. Fixes ship as 2.0.x from the `2.x` branch. Unsupported after that date |
```
