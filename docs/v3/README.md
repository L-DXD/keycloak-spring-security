# keycloak-spring-security v3

v3는 Spring Boot 4.1 · Spring Security 7.1 기준으로 라이브러리를 새로 짜는 판이다. 컨셉은 그대로 두고, 동작을 "BFF + JWT 쿠키 + DB 세션 행" 방식으로 바꾼다. 이 폴더가 v3 작업의 기준 문서다.

## 진행 방식

| 항목 | 규칙 |
|---|---|
| 묶음 이슈 | [#75](https://github.com/L-DXD/keycloak-spring-security/issues/75). v3 이슈는 모두 그 하위 이슈다. 진행 상황은 거기서 본다 |
| 판 | 3.0.0 = Servlet(#77~#91), 3.1.0 = WebFlux(#92). 마일스톤·라벨을 쓰려면 저장소 관리자가 만든다 |
| 이슈 | 기능 하나에 이슈 하나. 제목 `[v3-NN] ...`. 본문에 02 문서의 시나리오를 그대로 적는다 |
| 브랜치 | `v3` 통합 브랜치. 이슈마다 `v3/<이슈번호>-<짧은-이름>`에서 작업하고 `v3`로 PR |
| PR | 이슈 하나에 PR 하나. 제목 `[#번호] feat(v3): ...`, 본문에 `Closes #번호`. 리뷰와 머지는 이봉승 |
| 끝났다고 보는 때 | ① 그 이슈의 시나리오가 모두 자동 테스트로 통과 ② 01 설계와 GUIDE에 바뀐 점 반영 ③ CHANGELOG `[3.0.0] - Unreleased`에 한 줄 ④ 확장 지점 규칙(EXT-03~05) 통과 |
| 순서 | #78 빌드 → #77 검증 환경 → #79 설정 → #80 토큰 검증 · #81 저장소 · #82 쿠키 → #83 로그인 → #84 요청 → #85 갱신 → #86 CSRF·CORS → #87 로그아웃 → #88 back-channel → #89 이벤트 → #90 확장 지점 → #91 문서·배포 |
